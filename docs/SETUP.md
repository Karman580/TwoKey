# Setup and running locally

## Prerequisites

| Tool | Version tested | Check |
| --- | --- | --- |
| Go | 1.22+ (tested with 1.26) | `go version` |
| Python | 3.11+ (tested with 3.11.9) | `python3 --version` |
| make, curl | any | |

Docker is **not** required. The local demo runs on the dev ledger; see [ARCHITECTURE.md](ARCHITECTURE.md#9-deployment).

## Install

```bash
git clone https://github.com/Karman580/TwoKey.git
cd TwoKey
make setup
```

`make setup` creates `.venv`, installs the pinned Python dependencies from [`services/pyproject.toml`](../services/pyproject.toml), downloads the Go modules and runs [`scripts/gen_keys.py`](../scripts/gen_keys.py). That script writes `.env` with a fresh Ed25519 key pair per organisation and a random VPA-hash salt. `.env` is git-ignored and created with mode 600. To rotate the keys, run `python scripts/gen_keys.py --force`, then delete `.data/ledger.jsonl`, because old transactions will not verify against new keys.

## Run

```bash
make dev
```

This builds `.bin/devledger`, starts it on `127.0.0.1:8081`, waits for `/health`, then starts the services on `http://127.0.0.1:8000`. Open that URL. Press Ctrl-C to stop both.

Scripted demo against the running stack (second terminal):

```bash
make demo
```

API explorer (generated by FastAPI): `http://127.0.0.1:8000/docs`.

## Configuration

All settings are environment variables, loaded from `.env` by `scripts/dev.sh`. See [`.env.example`](../.env.example).

| Variable | Default | Meaning |
| --- | --- | --- |
| `TWOKEY_SECRET_KEYS` | generated | `Org=base64seed,...` for PayerBank, PayeeBank, NPCIObserver (services only) |
| `TWOKEY_PUBKEYS` | generated | Matching public keys (dev ledger only) |
| `VPA_HASH_SALT` | generated | HMAC salt for VPA hashes on the ledger; 16+ chars, required |
| `LEDGER_URL` | `http://127.0.0.1:8081` | Where the services reach the ledger |
| `DEVLEDGER_ADDR` | `127.0.0.1:8081` | Ledger listen address |
| `DEVLEDGER_DATA` | `.data/ledger.jsonl` | Append-only transaction log; delete it to start empty |
| `DEVLEDGER_ALLOW_CLOCK` | `1` | Enables the "+31 min / +4 h" demo clock. Set to `0` outside demos |
| `APP_HOST` / `APP_PORT` | `127.0.0.1` / `8000` | Services bind address |
| `HOLD_MEDIUM_SECONDS` / `HOLD_HIGH_SECONDS` | `1800` / `14400` | Tier holds; must satisfy `0 < medium ≤ high ≤ 14400` |
| `VALUE_FLOOR_PAISE` | `1000000` (₹10,000) | Small-amount exemption floor. An assumption: the proposal names a floor but no value |
| `KEEPER_INTERVAL_SECONDS` | `5` | How often expiries and settlement are reconciled |

## Test and lint

```bash
make test      # go vet + go test ./... ; pytest (starts the real Go ledger on a free port)
make lint      # gofmt + ruff
make simulate  # 1M-transfer simulation → simulator/results.json, docs/images/frontier.png
```

The same commands run in [CI](../.github/workflows/ci.yml).

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| `run 'make setup' first` | `.venv` missing; run `make setup` |
| `TWOKEY_PUBKEYS must list ...` | `.env` is missing or from an old format; run `python scripts/gen_keys.py --force` |
| `devledger did not start` / `address already in use` | Another process owns 8081: `lsof -i :8081`. Or change `DEVLEDGER_ADDR` and `LEDGER_URL` |
| Ledger exits with `replaying ...: INVALID_SIGNATURE` | Keys changed since the log was written; delete `.data/ledger.jsonl` |
| Dashboard pill says "ledger offline" | The ledger process died; restart `make dev` |
| Payment returns `LEDGER_UNAVAILABLE` | Expected when the ledger is down: risky payments fail closed and no money moves |
| Credits say "from an earlier demo session" | The services restarted (bank state is in memory) but the ledger log persisted. Harmless; delete `.data/ledger.jsonl` for a clean slate |
| `go: downloading go1.x` / toolchain errors | Run with `GOTOOLCHAIN=local`; the module needs only Go 1.22 |
